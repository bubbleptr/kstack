# ADR template

File: `docs/adr/NNNN-kebab-slug.md`. Number = highest existing + 1. Write in the project's documentation language (Chinese by default for Kieran's repos).

```md
# ADR-NNNN: <decision as a short statement>

- Status: Accepted
- Date: YYYY-MM-DD

## Problem

What forced a choice. The constraints a reader cannot see in the code.

## Decision

What we chose, stated so a reader can check the code against it.

## Alternatives

- <option> — one line on why it lost.

## Consequences

What this makes easy, what it makes hard, and anything that looks like an oversight but is deliberate.
```

One page at most. If it needs file paths or step-by-step instructions, those belong in the PR description instead.
